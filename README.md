# Spotify_Music_Streaming_Analysis
Power BI dashboard for analyzing Spotify music streaming data, popularity, genres, artists, tempo, energy and track duration.


📌 Project Overview

This project focuses on analyzing Spotify music streaming data using Microsoft Power BI. The dashboard transforms raw track-level data into interactive visual insights related to track popularity, genres, artists, tempo, danceability, energy, and track duration.

The main objective is to understand music trends and identify relationships between different audio characteristics and song popularity.

🎯 Project Objectives

- Analyze Spotify track-level music data.
- Identify the distribution of songs across different tempo ranges.
- Compare average popularity across music genres.
- Analyze the relationship between danceability and popularity.
- Analyze the relationship between energy and popularity.
- Examine track duration patterns.
- Build an interactive and visually appealing Power BI dashboard.
- Convert raw data into meaningful business and analytical insights.

🛠️ Tools & Technologies

- Microsoft Power BI – Dashboard development and data visualization
- Power Query – Data cleaning and transformation
- DAX – Measures and analytical calculations
- Microsoft Excel – Dataset preparation and analysis
- CSV – Source dataset

📈 Dashboard Analysis

1. Tempo Distribution of Hit Songs

The dashboard analyzes tracks based on different tempo ranges:

- Moderate (80–119 BPM)
- Fast (120–159 BPM)
- Very Fast (160+ BPM)
- Slow (Below 80 BPM)

The visualization shows that Moderate and Fast tempo ranges contain the highest number of tracks, while Very Fast and Slow categories contain comparatively fewer tracks.

This helps understand the tempo patterns commonly found within the analyzed music dataset.

2. Average Popularity by Genre

The dashboard compares average popularity across different genres.

This visualization helps identify which genres contribute more strongly to the overall popularity levels within the dataset.

3. Danceability vs Popularity

The scatter chart compares danceability with popularity for individual tracks.

This analysis helps explore whether songs with higher danceability scores tend to achieve higher popularity. The distribution shows that popularity varies across different levels of danceability, indicating that danceability alone does not completely determine a track's popularity.

4. Energy vs Popularity

The dashboard also analyzes the relationship between energy and popularity.

The scatter plot shows the distribution of tracks across different energy levels and popularity scores. This helps identify whether energetic songs consistently receive higher popularity or whether popularity is influenced by multiple audio characteristics.

5. Track Duration Analysis

The dashboard provides an average track duration of approximately 3.72 minutes for the analyzed popular tracks.

This metric provides an overview of the typical duration of tracks within the dataset.

🔍 Key Insights

- The dataset contains approximately 2,000 tracks from 544 artists.
- Moderate and fast tempo categories contain a larger proportion of the analyzed tracks.
- The average popularity score across the dataset is approximately 36.44.
- Track popularity varies across genres.
- Danceability and energy show varied relationships with popularity rather than a simple one-to-one relationship.
- The average track duration is approximately 3.72 minutes.
- The dashboard provides an interactive way to explore relationships between different music characteristics.
